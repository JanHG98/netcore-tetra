# NetCore-Tetra Open-Lab E2E Tests

Inventory-gesteuerte Tests für das Zusammenspiel der Backend-Dienste im isolierten Open Lab. Runner, Szenarien und Ergebnisnachweise liegen in diesem Verzeichnis.

Das Beispielinventar enthält 26 reguläre Dienste. `--validate-only` prüft den Ablauf ohne Dienstkontakte; ein solcher Erfolg belegt keine erreichbare Anlage.
