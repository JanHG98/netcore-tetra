# Auftragsbearbeitung

Task Workflow verwaltet strukturierte Aufträge und kompakte WAP-Formulare. Der Dienst läuft als eigener LXC auf Port `8280` und bleibt im OPEN-LAB-Modus ohne Login, Token und TLS.
