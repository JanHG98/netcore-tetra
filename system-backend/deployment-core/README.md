# Installation, Discovery und Pi-Images

Eine **Ubuntu-VM** für WebUI, Auto Discovery, Deployments und bootfähige Pi-Images, dazu ein Discovery-/Deployment-Agent pro bestehendem LXC bzw. Pi. Controller/Agent: Python **3.11 oder neuer**, nur Standardbibliothek. Die Oberfläche, API und Discovery verwenden OpenLab: **kein Login, keine Tokens, kein TLS, keine Zertifikate, kein RBAC**. Erreichbare Teilnehmer im Lab können Installationen und Neustarts auslösen. GitHub und Paketquellen werden weiterhin über ihre normalen HTTPS-Adressen abgerufen.
