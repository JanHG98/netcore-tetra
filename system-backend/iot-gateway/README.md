# IoT-Anbindung

Der IoT Gateway verbindet `netcore-event-v1` mit MQTT, verarbeitet `netcore-command-v1` über Default-Deny-Policies, quittiert mit `netcore-command-ack-v1` und bindet Home Assistant sowie Homematic IP an.
