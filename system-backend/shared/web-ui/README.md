# NetCore Shared WebUI

Build-freie CSS- und ES-Modul-Bausteine für die Verwaltungsoberflächen der Backend-Dienste. Die Assets benötigen weder Node.js noch einen zusätzlichen Frontend-Container in Produktion.

Die Bausteine vereinheitlichen das Erscheinungsbild; Anmeldung und Berechtigungen bleiben Aufgabe des jeweiligen Dienstes.

Lokale Dateien: [tests](tests/).
