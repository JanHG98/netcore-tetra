# Transit – Quellpaket

Native Vermittlung zwischen NetCore-Regionen mit Routing, Queues und Failover. Standardport 8200; `netcore-transit-v1` ist noch kein ETSI ISI. Management und Peer-Zugriff sind im Open Lab ungeschützt.
