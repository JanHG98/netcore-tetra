# NetCore-Tetra Entwicklungswerkzeuge

`protocol_inventory.py` erzeugt die statische PDU-, SAP-, Gap- und State-Machine-Inventur.

Die lesbaren Ausgaben stehen zentral unter `Docs/protocols/`. `--check` vergleicht sie mit dem aktuellen Rust-Quellbaum; die statische Inventur ersetzt keinen Laufzeit- oder Funkversuch.
