# NetCore Academy: erhaltene Inhalte und rekonstruierte Bildvorschauen

Zugehörige Abschlussdokumentation: [NetCore Academy](../../2026-10-06_netcore-academy-moodle-kurssystem-noob-bis-bitdecoder.md).
