# MS-Modus

Separater Cargo-Workspace für den TETRA-MS-Modus (`0.5.9`, Beispielkonfiguration `0.7`, externe Schnittstelle `bluestation-ms-interface-6`). Build- und Testbefehle hier im Verzeichnis `ms-mode` ausführen. Der Einstieg beschreibt Aufbau und Betrieb; die Schnittstellendokumentation erklärt die Kommunikation mit externen Anwendungen.
